# NOIRÉ — Premium Saudi Eyewear Experience

A significantly expanded React/Vite premium eyewear demo for a Saudi luxury eyewear client.

## Expanded experience

- Premium editorial homepage with luxury art direction
- 16-product collection with search, filters and sorting
- Individual product pages with multi-image product gallery, specifications and related products
- Dedicated visual archive / Gallery page with masonry editorial layout
- Our Story / brand house page
- Services / private fitting experience page
- Journal / editorial content page
- Stores page for Riyadh, Jeddah and Dammam
- Private fitting / Contact page with inquiry form
- Bag / WhatsApp ordering flow
- English + Arabic language switch with RTL support
- Responsive desktop, tablet and mobile layouts
- Premium typography, transitions, muted luxury palette and editorial spacing
- High-resolution Unsplash photography

## Run

```bash
npm install
npm run dev
```

Replace the demo WhatsApp number, email, map links and business details before client delivery.

## Note

Photography uses remote Unsplash URLs and therefore requires an internet connection.
